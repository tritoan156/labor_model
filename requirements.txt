# Floor versions — Streamlit Cloud picks compatible patch/minor releases.
# Bump the floors when the team validates a newer combination locally.
#
# 1.51+ required: the app sizes every element with width="stretch" (buttons
# gained `width` in 1.48, dataframe/data_editor/graphviz in 1.49, plotly_chart
# in 1.51). The old use_container_width= kwarg is deprecated and scheduled for
# removal, so with no upper cap here a Cloud version bump would break the app
# if we ever fell back to it. 1.36+ (column_config pinned=True, which keeps
# SKU/Description frozen in the catalog editors) is implied by this floor.
# 1.57+ required for the top-level tab strip (st.segmented_control with
# required=True and width="stretch") and the @st.fragment tab bodies that keep
# each click to one panel. Validated locally on 1.57; Streamlit Cloud runs 1.58.
streamlit>=1.57
# Cap below pandas 3: core/data_loader.py disables the Arrow-string default via
# `pd.set_option("future.infer_string", False)`. That option is removed in
# pandas 3 (Arrow strings become mandatory), where the try/except shim silently
# no-ops and the Arrow <NA>/dtype bugs it guards against return in production.
# Lift the cap only after a validated pandas-3 Arrow-compat pass (see MAINTAINING.md).
pandas>=2.0,<3
plotly>=5.20
openpyxl>=3.1
requests>=2.31
